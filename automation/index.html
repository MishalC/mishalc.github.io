Release tracking

Live from July 2026, and tracked over 100 releases by October 2026. It tracked releases and posted notes. It did not deploy anything.

  1. GitHubA production release goes out
  2. GitHubRelease tracking automation runs in CI
  3. LinearCreates the release and collects its issues
  4. AIWrites the release notes
  5. SlackPosts the notes for the team
  6. SlackReplies in the reporter’s own thread

Triage and routing

Nothing changes in Linear until a person approves it.

  1. SlackSomeone reports an issue and tags the agent
  2. AILinear’s Slack agent makes a structured ticket
  3. LinearTriage suggests routing from AI guidance I set
  4. AIDaily triage routine checks for duplicates
  5. YouA person reviews the proposed actions
  6. AITriage skill applies what was approved
  7. LinearTicket goes to the owning team
