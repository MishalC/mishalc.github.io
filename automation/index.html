Pull request board

An internal dashboard I built on my own for the engineering team, AI-assisted. It reads every open pull request from GitHub and refreshes every 30 minutes.

Problem
There were a large number of open pull requests at any one time. GitHub’s own lists had no easy way to filter them, or to show which were waiting on review, failing checks, in the merge queue or blocked.
Solution
One board for every open pull request, grouped by stage: review, CI, merge queue and blocked. It adds quick filters, a personal view of each engineer’s own work and a history of what merged.

Redrawn concept

A clickable redrawing of the board, written fresh with placeholder data. The real board, its code and the team’s pull requests are not shown.
