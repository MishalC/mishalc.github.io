Three rules for AI

AI-assisted means an AI coding agent writes the code and I specify, test and fix it: 39 merged pull requests and over 15 internal tools and automations so far, under three rules.

I specify, test and fix. The agent writes.

Every change starts with a brief from me and ends with my test on the local product stack. Review feedback goes back to the agent, and I test again.

  1. YouI specify the change
  2. AIAI coding agent writes the code
  3. YouI test and fix on the local stackA person decides hereFix round: back to step 2
  4. GitHubPull request reviewed and merged

A second AI pass argues with the first.

On the backlog audit, the second pass tried to prove the first pass wrong before I saw either. The figures are on the audit strip above.

  1. AIFirst pass flags tickets to close or route
  2. AISecond pass challenges the keeps, overturns none
  3. YouI approve each close and record whyA person decides here
