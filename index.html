How I work with AI

AI-assisted means an AI coding agent writes the code, and I specify, test and fix it. Three rules, each drawn as the flow it produces.

  • 39merged pull requests, AI-assisted
  • 15interactive prototypes, AI-assisted
  • 15+internal tools and automations, AI-assisted
  • 125production releases with AI-written notes

I specify, test and fix. The agent writes.

Every change starts with a brief from me and ends with my test on the local product stack. Review feedback goes back to the agent, and I test again.

  1. YouI specify the change
  2. AIAI coding agent writes the code
  3. YouI test and fix on the local stackFix round: back to step 2
  4. GitHubPull request reviewed and merged

A second AI pass argues with the first.

On the backlog audit, the second pass tried to prove the first pass wrong before I saw either. The figures are from the audit record.

  1. AIFirst pass flags 131 of 576 tickets
  2. AISecond pass challenges 30 keeps, overturns none
  3. YouI approve each close and record why
  4. Linear95 tickets closed

Nothing enters the tracker without my approval.

Agents, routines and skills propose. A person approves. One short pilot of AI inside the tracker ran without that step.

  1. AIAn agent, routine or skill proposes
  2. YouI review and approve
  3. LinearOnly then the tracker changes
